## The shape of an address

Every entry lives at `/{type}/{uid}v{version}`. ^shape

- `type` is what kind of entry it is, such as `p` for a post or `rfc` for an RFC.
- `uid` is a hex counter that starts at 0 for each type.
- `version` is `major.minor.patch`, with trailing zeros left off. ^version
  - A major change is a change of mind.
  - A minor change adds or clarifies.
  - A patch fixes spelling or formatting and never changes meaning.

## Other ways in

| Address               | Opens                                           |
| --------------------- | ----------------------------------------------- |
| `/psa/0`              | every version, with what changed                |
| `/psa/0l`             | the latest version                              |
| `/psa/0v1`            | exactly version 1                               |
| `/psa/0v1+`           | the newest version; the link was made from v1   |
| `/psa/0v1.1+`         | the newest patch of v1.1                        |
| `/psa/0v1.1/addresses`| the same page, with a readable name on the end  |
